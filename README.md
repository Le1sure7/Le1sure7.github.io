# 夜色手记（暂定站名）
双击 index.html 本地预览。发布时将本目录文件放入 GitHub 仓库 main 分支根目录，在 Settings → Pages 选择 Deploy from a branch → main → / (root)。
- 修改文字：在 index.html 和 post.html 修改站名，在 index.html 修改首页介绍。
- 写博客：修改 content.js 的 posts；每篇使用唯一 id，把新文章放在数组开头，日期用 YYYY-MM-DD。
- 配色、布局和动画：style.css。背景图：assets/night.png。
- 配置音乐：将有权发布的音频放进 assets，在 content.js 的 playlistTrack 填写 title 和相对路径 src。访客也可以选择自己的本地音频，文件仅在浏览器内播放。
- 设计及夜景图片来源：https://github.com/leleo886/leleo-home-page ，附模板许可证 assets/template-LICENSE.txt。
