## 写博客

每篇文章一个文件，放在 `library/`，再把文件名（不含 `.js`）登记到 `content.js` 的 `libraryFiles` 清单。`id` 需要唯一，日期使用 `YYYY-MM-DD`，`category` 是一个分类，`tags` 是标签数组。旧文章的 `tag` 字段和 `paragraphs` 正文仍可读取。

`markdown` 字段支持标题、嵌套列表、粗体、引用、链接、图片、表格和代码块。标题自动进入文章目录，阅读时间按正文估算。有日期的文章按年月归档。首页筛选可以组合使用，点击搜索结果会打开文章并定位到第一处正文匹配。

- 代码围栏可以使用三个反引号或三个波浪号。标注 `cpp`（也支持 `c++`）、`python` 或 `javascript`（也支持 `js`）可启用语法高亮。代码块支持一键复制。
- 行内公式使用 `$E=mc^2$` 或 `\(E=mc^2\)`。独立公式使用 `$$…$$` 或 `\[…\]`。
- 图片使用 `![图片说明](assets/example.png)`，视频使用 `![视频说明](assets/example.mp4)`。可用的文件扩展名为 `.mp4`、`.webm` 和 `.ogv`，播放取决于浏览器支持的编码。站内资源路径相对于 `index.html` 和 `post.html`。
- 把自包含的 HTML、CSS 或内联 JavaScript 放进标注为 `animation` 的代码围栏。读者展开后，动画在沙盒内运行，关闭即停止。动画中的 CSS 会遵守系统的减少动态效果设置。

正文顶层内容从行首写起，列表可用空格缩进。在普通 JavaScript 模板字符串中，需要转义反斜杠、反引号和字面量插值。使用波浪号围栏可以减少转义。原始文章草稿可以放在 `Essays/`。

GitHub Pages 直接使用仓库里的静态文件。双击 `index.html` 也能预览，渲染依赖均随站点提供。升级依赖后，运行 `npm ci` 和 `npm run build:vendor`，提交更新后的依赖锁文件和 `vendor/` 产物。
